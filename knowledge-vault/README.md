# Path2Uni Knowledge Vault

This Obsidian vault is a curated analyst workspace. PostgreSQL remains the source of truth.

Folders:

- `00 Inbox` — unreviewed notes and imports.
- `10 Universities` — one note per institution.
- `20 Programs` — one note per degree program.
- `30 Admissions` — cycle-specific requirements and deadlines.
- `40 Scholarships` — financial-aid opportunities.
- `50 Sources` — source summaries and provenance.
- `60 Research` — thematic OSINT research.
- `70 Decisions` — architecture and data decisions.
- `90 Templates` — note templates.

Only reviewed notes should contain `status: verified`. Every factual note must include `source_urls`, `accessed_at`, and a period such as `academic_year` or `valid_for`.
